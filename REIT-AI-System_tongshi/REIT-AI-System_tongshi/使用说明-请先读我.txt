========================================================
  REIT-AI 申报材料生成系统 · 使用说明（请先读我）
========================================================

【第一步：装 Python（只需一次）】
  1. 打开 https://www.python.org/downloads/ ，下载 Python 3.12.x（Windows 版）。
  2. 安装时，第一屏一定要勾选最下面的 “Add python.exe to PATH”，再点 Install。
  （如果电脑已经装过 Python 3.12，可跳过这一步。）

  ★ 版本务必是 3.12.x！不要装 3.13 / 3.14 —— 更高版本上 PyMuPDF 等依赖
    还没有对应的安装包，会安装失败、一启动就崩。若已装了更高版本，
    到“设置→应用”里卸载，再装 3.12.x。

【第二步：启动网站】
  双击本文件夹里的  “run.bat”
  - 第一次会自动安装依赖，需要几分钟，请耐心等待（黑窗口里有进度）。
  - 装好后会自动打开浏览器，地址 http://127.0.0.1:8000
  - 以后再用，直接双击 “run.bat” 即可，秒开。
  - 想关闭网站：把那个黑色命令行窗口关掉就行。

【第三步：设置两个路径（第一次用各做一次）】
  进入网站后点左侧 “系统设置”，设置下面两个路径：

  1) “模板文件路径” —— 选官方模板文件（在 “AI test” 文件夹根目录下）：
        基础设施领域不动产投资信托基金（REITs）项目申报材料格式文本（2024年版）.docx
     设好后，各章的小标题、Word 预览、导出才会正常。

  2) “申报材料路径” —— 选证明材料文件夹（在 “AI test” 文件夹根目录下）：
        奥飞数据中心基础设施领域不动产投资信托基金（REITs）项目相关证明材料
     设好后，生成时 Kimi 才能去读承诺函、审计报告等文件、据实填写。
     （不设也能生成，但需要看文件的地方会标注“待核实”。）

  ★ 这两个路径存在浏览器本地、且是各自电脑上的完整路径；换了电脑要重新选一次，
    直接指到这台电脑上 “AI test” 里对应的那个文件 / 文件夹即可。

【重要提醒】
  1. 请保持整个 “AI test” 文件夹在一起、不要只拷其中的网站子文件夹——
     系统要读取 “AI test\skills” 里的写作规则，以及模板、证明材料。
     放到任意盘符/位置都行，但内部结构不要改。
  2. Kimi 大模型的密钥已放在 .env 文件里（大家共用一个），无需改动。
     如需换模型，进网站 “系统设置 → Kimi 模型” 里选即可；
     首次使用可先在那里确认模型能正常拉取、调用。
  3. 需要联网：安装依赖、调用 Kimi / 天眼查 / 联网搜索都要联网，
     但【不需要翻墙】——这些都是国内服务（如 api.moonshot.cn），画图工具已内置在本地。
  4. 如果 python.org 下载太慢，可用国内镜像：https://mirrors.huaweicloud.com/python/

【常见问题】
  - 双击 bat 后提示没有 Python：第一步没装好，或安装时没勾 “Add to PATH”，
    重装一次（3.12.x）并勾选即可。
  - 双击后闪退、或提示缺少某个模块（如 fitz / fastapi 等）：说明依赖没装全。
    run.bat 每次启动都会自动检查依赖、缺了就自动装，正常直接重新双击一次即可；
    若仍失败，多半是网络问题，见下一条手动用国内镜像装。
  - 依赖安装很慢或失败：多半是网络问题。可在黑窗口里手动用国内镜像安装：
        python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
    装完再双击 “run.bat”。公司网络如需代理请联系 IT。
  - 浏览器没自动打开：手动在浏览器输入 http://127.0.0.1:8000
  - 小标题 / 预览 / 导出不正常：多半是没设 “模板文件路径”，回到第三步设一下。
