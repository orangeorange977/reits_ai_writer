# REITs发改委申报材料 · 第六章：运营管理安排

## 共享项目信息

写作前先读取 `../planning.md`（`skills/` 目录下所有 skill 共用，存放当前申报项目的基础信息，如项目名称、所属基础设施REITs行业领域、模板/勾稽表/证明材料文件夹路径等）。**正文中凡是遇到 `planning.md` 里已经定义的字段，直接引用该文件中的值，不要重新推测、重新查证或与之不一致地手写。** `planning.md` 未覆盖的字段，仍按本skill下方流程自行查证。

## 本skill负责的范围

官方模板中"六、运营管理安排（测试修订）"整章（本测试包六章结构的最后一章，其后不再是第七章，而是模板尾部的证明材料部分）。本章通常**全部是叙述性文字，没有固定表格**，但仍需先运行：
```
python scripts/read_chapter.py "<模板路径>" "六、运营管理安排（测试修订）"
```
确认本项目实际使用的模板版本是否加了表格或改了小节结构——不要假设一定和以前的项目一样。

## 本章要覆盖的核心问题（模板一般会要求说明）

- 运营管理机构是谁、承担哪些具体职责（设施维保、招商、账款催收、信息披露配合等）。
- 收费机制：运营管理机构如何取得报酬（通常是基础管理费+浮动/激励部分），费率是否市场化。
- 基金管理人对运营管理机构的监督机制（定期报告、实地核查、必要时委托第三方审计等）。
- **如果运营管理机构和某个发起人（原始权益人）是同一实体或存在关联关系，必须专门说明关联交易和利益冲突的防范措施**（费率如何避免利益输送、是否有信息隔离墙、公平交易管理制度、关联交易审议披露程序等）。这一点很容易被写得笼统，建议具体到"谁来审议""按什么标准定价"。

## 工作流程

1. 运行 `scripts/read_chapter.py` 确认本章实际结构。
2. 结合第二章（`reits-reading-ch2`）已经确定的运营管理机构身份，判断是否存在关联关系，需要写利益冲突防范部分。
3. 如证明材料文件夹里有基金管理人关于同类项目的利益冲突防范机制说明（比如同一基金管理人管理多个同类项目时的隔离安排），一并检索引用。
4. 生成内容，遵守【注：】标注规范。
5. 按下方"输出格式"写出 `ch6.json`，交给 `reits-writing` 统一写入文档。
