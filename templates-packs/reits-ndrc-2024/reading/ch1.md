# REITs发改委申报材料 · 第一章：项目基本情况

## 共享项目信息

写作前先读取 `../planning.md`（`skills/` 目录下所有 skill 共用，存放当前申报项目的基础信息，如项目名称、所属基础设施REITs行业领域、模板/勾稽表/证明材料文件夹路径等）。**正文中凡是遇到 `planning.md` 里已经定义的字段，直接引用该文件中的值，不要重新推测、重新查证或与之不一致地手写。** `planning.md` 未覆盖的字段，仍按本skill下方流程自行查证。

## 本skill负责的范围

官方模板中"一、项目基本情况"整章，止于"二、参与主体情况"之前。先运行：
```
python scripts/read_chapter.py "<模板路径>" "一、项目基本情况" "二、参与主体情况"
```
确认模板实际结构。标准基线三节：（一）项目概况；（二）特殊限定情况说明；（三）可扩募资产情况。表1、表2为官方模板给定表格，表题/行项/表头以模板实际读出为准。

**术语口径**：产品层称谓（基础设施基金/基础设施REITs）按 `planning.md` 口径与基金合同登记名称统一替换（新体例为"不动产基金"），同一文档内不得混用；"基础设施项目""项目公司"等资产层术语维持现行口径。

# 第一章：项目基本情况

## （一）项目概况

表前正文为一段总述（多子项目时逐一分述），按以下要素顺序完整覆盖，与表1数值零偏差一致：

本项目名称是【项目名称】，标的资产为【底层资产名称】，位于【资产所在地（详细地址）】。资产范围为【项目四至/起止地点】，总体建设规模为【建设规模（万元）】，土地面积为【土地面积】㎡，建筑面积为【建筑面积】㎡，【行业核心规模指标，如机柜共X个/里程X公里】，于【运营起始时间】开始运营，标的资产于价值时点【申报基准日】的资产评估值为【评估值（亿元口径）】。本项目类型为【所有权类/经营收益权类】。

如运营起始时间早于竣工验收时间（先投运后补验收），须紧随其后说明原因及各项竣工验收手续的后续取得情况（含取得日期与文件名称），不得回避该时间差。

**注意：下表中"项目总体情况""子项目1""子项目2"……这类行是分节标题行，只起分隔/小标题作用，value 一律留空，不要填任何内容（哪怕手里有摘要表等数据也不要往这些行里填）；只有其余带具体字段名的行才需要填值。**

**表#填表口径（通用要求，适用于任何项目；所有值一律由你读材料自行提取，不得照搬本文件里的举例）：**
- 表题（caption）一律写占位"表#"，不得自写数字编号（writing 侧按出现顺序自动排成 表1-1、表1-2）；表1表题带基准日后缀，写作"表#  项目概况（基准日【申报基准日】）"，与定稿版式一致；表2表题维持模板原文"表#  发起人（原始权益人）可扩募资产情况"。括号后缀重编号时会被原样保留。
- 行项名以模板实际读出为准，逐字照抄，不得增删括号提示或自行改写（如"运营起始时间（年月）""项目权属起止时间及剩余年限（剩余年限为权属到期日与申报基准日之差）"）。
- 正式名称口径：项目/子项目的正式名称，以不动产权证书、国有建设用地使用权出让合同、法律意见书等权属文件上登记的正式名称为准；不得用项目别名、立项/可研阶段名称充当正式名称。
- 字段值语义匹配：值必须与字段名暗示的单位和语义一致——带（万元）的字段填金额数字（千分位、两位小数），不得填面积、数量等文本；"项目建设规模合计"行模板未标注单位，值以万元口径填写并带"万元"后缀，与带（万元）行的纯数字区分。
- 时间口径：时间类字段材料中有具体日期的写到年月日（如"【年】年【月】月【日】日"）；"运营起始时间（年月）"至少写到年月。
- 单元格内分多行：同一单元格内需分两行写的信息，值内用 \n 分隔，系统渲染为单元格内换行。开竣工时间行两行分写："开工时间为【日期】\n竣工时间为【日期】"；权属行两行分写："【权属起始日】至【权属到期日】\n剩余年限：【X.XX】年"（剩余年限=权属到期日与申报基准日之差，保留两位小数）。
- 行业领域表述：按发改委行业分类口径表述为"XX基础设施 — XX类"（如"新型基础设施 — 数据中心类"）。
- 资产范围：非线性工程填写项目四至（东、西、南、北边界）；线性工程填写起止地点；材料中有"具体范围以土地出让合同后附的测绘图为准"之类约定表述的，连同合同编号、附件编号一并完整摘录。

## （二）特殊限定情况说明

看下该项目的【行业领域】：

1.对于燃煤发电项目，应说明项目具备以下一项或多项条件的具体情况：纯凝工况最小发电出力在30%额定负荷及以下；掺烧生物质、氢、氨等低碳燃料，掺烧热量比例不低于10%；配备大规模碳捕集利用与封存（CCUS）设备。

2.对于园区基础设施项目，如项目底层资产中包括酒店、配套底商，应详细说明酒店、配套底商的权属情况；与底层资产中的园区基础设施部分资产的物理关联关系，如是否为同一栋建筑；纳入底层资产的酒店、配套底商合计占同一单体建筑的面积比例。

3.对于文化旅游基础设施项目，如项目底层资产中包括配套旅游酒店，应详细说明旅游酒店的权属情况，地理位置情况，是否在景区规划范围内。

4.对于消费基础设施项目，如项目底层资产中包括酒店、商业办公用房，应详细说明酒店、商业办公用房的权属情况；与底层资产中的消费基础设施部分资产的物理关联关系，如是否为同一栋建筑；说明底层资产中酒店、商业办公用房的建筑面积占底层资产总建筑面积的比例。

如果【行业领域】不涉及上述4个类型，则直接输出"不涉及。"，不要输出其他文字。如涉及，则逐项详细说明对应情况。

## 工作流程

1. 运行 `scripts/read_chapter.py` 确认本章实际结构与表1/表2实际行项、表头、注。
2. 读取 `planning.md`，确认项目名称、行业领域、申报基准日；在证明材料文件夹检索：不动产权证书、国有建设用地使用权出让合同、施工许可证、竣工验收备案证明、评估报告、审计报告、发起人说明/招募说明书等。
3. 表1以权属证照与评估报告为一手来源，（三）以发起人材料与经审计财务报表为一手来源，数字零偏差搬运。
4. 生成内容，遵守【注：】标注规范，按下方"输出格式"写出章节 JSON，交给 `reits-writing` 统一写入文档。
