# 第二章主体与财务专项提取

本通道直接对标第二章表3—10，不以“已提取主体名称”作为完成。执行时参考
`AI test/skills/reits-reading-ch2/SKILL.md` 的逐表取数口径，但以本 SKILL 的字段、
溯源和验收规则为准。

## 先建主体账

1. 从营业执照、章程、信用报告和法律意见书列出全部项目公司、发起人（原始权益人）、运营管理机构和中介机构。
2. 每个项目公司填齐：公司名称、法定代表人、成立日期、注册资本、注册地址、经营范围。
3. 每个发起人填齐：公司名称、法定代表人、实际控制人、成立日期、注册资本、注册地址、主营业务、已发行REITs情况、近12个月退回情况。
4. 项目公司全部股东与持股比例合计100%；控股股东和最终实际控制人分开记。

## 财务数据四维建账

对每个发起人建立“主体×报表期间×指标×来源”记录。要求最近3个完整会计年度及最近一期，表头以报表原文为准。不要从报告开头顺读等待偶然命中，先定位合并资产负债表、合并利润表、合并现金流量表；通常位于前15页，未找齐再继续全文检索。

| 指标 | 取数位置 |
| --- | --- |
| 总资产 | 合并资产负债表“资产总计” |
| 总负债 | 合并资产负债表“负债合计” |
| 资产负债率 | 总负债÷总资产×100%，保留两位小数，保留公式与两个输入来源 |
| 营业收入 | 合并利润表“营业总收入”；没有“总”时用“营业收入” |
| 净利润 | 合并利润表“净利润” |
| EBITDA | 只提材料直接披露值；不代算 |
| 经营活动现金流量净额 | 合并现金流量表同名行 |

数值全部统一为万元，但 `_raw_text` 保留原币种、原单位和原值。资产负债表取期末数，利润表和现金流量表取本期累计数；不得把期初数或上年同期数写入本期列。同一年报告含上年比较数时，与上年审计报告勾稽；重述数与原报数并存并标明采用口径。

## 变动原因与标记

对总资产、总负债、营业收入、净利润、经营活动现金流量净额计算相邻年度变动幅度；资产负债率计算百分点变动。以下任一情况登记到 `entities.originators[*].financial_analysis.change_reasons[]`：

- 绝对变动幅度不低于20%；
- 由负转正或由正转负；
- 净利润或经营现金流为负；
- 资产负债率变动不小于5个百分点。

原因按优先级查找：审计报告附注→年报“管理层讨论与分析”→业务提供的专项说明。能解释时 `status=explained` 并记原文来源；不能解释时 `status=unexplained`、`reason=null`，不得根据行业特征推测。变动幅度用于正文标记，不生成独立同比表。

## 完成判定

表3—10每个应填格都有值或明确缺口；每个发起人的财务期间完整；所有重大变动都有 `explained/unexplained` 状态。缺一个主体或一个期间不得以其他主体数据代填。
