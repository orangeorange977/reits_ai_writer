# REITs发改委申报材料 · 第七章：募集资金用途情况

## 共享项目信息

写作前先读取 `../planning.md`（`skills/` 目录下所有 skill 共用，存放当前申报项目的基础信息，如项目名称、所属基础设施REITs行业领域、模板/勾稽表/证明材料文件夹路径等）。**正文中凡是遇到 `planning.md` 里已经定义的字段，直接引用该文件中的值，不要重新推测、重新查证或与之不一致地手写。** `planning.md` 未覆盖的字段，仍按本skill下方流程自行查证。

## 本skill负责的范围

官方模板中"七、募集资金用途情况"整章，直到文档结尾（含附件1证明材料清单、附件2法律意见书必备内容两个附件）。包含：
（一）规模及使用结构+表23；（二）资金流向图；（三）拟投资项目情况+表24；（四）拟收购存量资产情况+表25；（五）其他情况。

先运行 `scripts/read_chapter.py <模板路径> "七、募集资金用途情况"`（不传第三个参数，读到文末）拿到本章及两个附件的真实结构。

## 本章内容的关键来源与常见情况

- "（二）资金流向图"：把募集资金从基金到项目公司/发起人等各方的流转路径整理成"谁流向谁、标什么字"的清单，交给 `reits-diagrams` skill 画图，生成 `ch7_diagrams.json` 后和 `ch7.json` 一起交给 `reits-writing` 装配（用法同第二章的股权结构图，见 `reits-diagrams` 的SKILL.md），本skill自己不画图。
- 表23"（拟）缴纳税费情况"这一行，直接引用第五章表22（税收处理）算出的税费合计，两处数字必须一致，不要各写各的。
- "拟投资项目情况""拟收购存量资产情况"（表24/25）：很多项目在申报阶段还没有确定具体的净回收资金投向，这种情况下模板本身也允许留待基金份额公开发售前再披露，如果证明材料里确实没有具体项目清单，如实标注【注：尚未确定，将在基金份额公开发售前披露】即可，不要为了填满表格编造项目。
- "净回收资金2年/3年使用率"等承诺条款：一般发起人会出具专门的承诺函，去证明材料文件夹里找"关于回收资金使用的承诺函"之类的文件，承诺的具体比例（如"2年内不低于75%"）以承诺函原文为准，不要凭行业惯例猜一个数字。
- 附件1（证明材料清单）：这部分本质上是把前面7章用到的所有证明材料按模板编号整理成一张清单，可以在写完前面章节、确定了每份材料对应模板哪个编号之后再统一整理，不需要重新做实质性判断。
- 附件2（法律意见书必备内容）：通常是模板给的一段固定的格式要求文字，说明"转让行为合法性"法律意见书应包含哪些内容，一般不需要项目方自己撰写正文，除非模板要求填入本项目已出具的法律意见书具体结论摘要——请以第1步读出来的模板原文为准判断是否需要填内容。

## 工作流程

1. 运行 `scripts/read_chapter.py` 拿到本章及附件的真实结构。
2. 读取项目根目录勾稽xlsx，定位（七）章节对应的证明材料子文件夹编号（承诺函、资金用途相关文件）。
3. 核对表23税费数据与第五章表22的一致性。
4. 生成内容，遵守【注：】标注规范。
5. 按下方"输出格式"写出 `ch7.json`，交给 `reits-writing` 统一写入文档——建议放在最后一个执行，因为附件1的证明材料清单最好在其余6章都定稿后再整理。
